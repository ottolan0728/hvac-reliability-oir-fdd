# OIR-FDD: Reliability Evaluation for Cross-System HVAC Fault Diagnosis

Reproducibility repository for:

**Beyond Accuracy: Identifiability and Reliability Limits of Cross-System HVAC Fault Diagnosis under Distribution Shift**

Authors:
- Chun-Jan Tseng
- Yi-Kai Su
- Ming-Han Chang

## Framework

- **OIR-FDD** — Observability–Identifiability–Reliability evaluation framework
- **IGTI** — Identifiability-Gated Transfer Interpretation
- **CRRA** — Class-Retention Reliability Audit

## Data availability

The study uses publicly released HVAC fault-detection datasets cited in the manuscript.
Raw third-party datasets are not redistributed here unless their licenses explicitly permit redistribution.
The repository instead provides source-data provenance, split/eligibility definitions, derived artifacts,
and reproducibility material.

## Repository structure

- `manuscript/` — LaTeX manuscript source
- `supplementary/` — supplementary source
- `algorithms/` — IGTI and CRRA descriptions
- `data_manifest/` — provenance and download instructions
- `reproducibility/` — frozen-evidence and validation notes
