# Reproducibility boundary

The manuscript was developed under a frozen-evidence workflow.

Key rules:
- source-governed model/calibration selection;
- target outcomes used for evaluation, not retuning;
- explicit observability and eligibility contracts;
- source identifiability audited before transfer-failure claims;
- class-retention checks for calibration/selective reliability;
- persistent sensor-loss stress and source-governed fallback;
- semantic/graph variants retained as controlled ablation evidence.

This repository is intended to expose the manuscript source, deterministic audit logic,
data provenance, and non-restricted derived artifacts.
