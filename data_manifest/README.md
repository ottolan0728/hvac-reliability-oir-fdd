# Dataset manifest

Do not commit third-party raw HVAC datasets unless redistribution is explicitly permitted.

For each source dataset, record:
- canonical citation and provider
- download URL
- acquisition date
- expected file/archive hashes
- extraction layout
- redistribution status
- role in the manuscript (e.g., RTU simulation/laboratory, SFPU, PFPU)

Internal development labels such as Track A/B/C are intentionally not used here.
